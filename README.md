# 🤠 Aperos Puro Coleo - E-Commerce Full-Stack

![Aperos Puro Coleo Banner]

**Aperos Puro Coleo** es una aplicación web de comercio electrónico de alta gama diseñada para la venta de artículos llaneros, sombreros vaqueros y aperos. Desarrollada con una arquitectura cliente-servidor, ofrece una experiencia de usuario fluida con filtros en tiempo real y un panel de administración respaldado por una base de datos NoSQL.

## 🚀 Tecnologías Utilizadas

### Frontend
* **Framework:** Angular 17+ (Standalone Components)
* **Gestión de Estado:** Angular Signals (`signal`, `computed`)
* **Estilos:** CSS3 Puro (Custom Properties, Grid, Flexbox, Responsive Design)
* **Iconos:** Lucide Angular

### Backend & Base de Datos
* **Entorno:** Node.js
* **Framework:** Express.js
* **Base de Datos:** MongoDB Atlas (Cloud)
* **ODM:** Mongoose
* **Middleware:** CORS, Dotenv

---

## ✨ Características Principales

* **Catálogo Dinámico:** Los productos y categorías se cargan en tiempo real desde MongoDB.
* **Buscador Inteligente:** Filtra productos instantáneamente por nombre o descripción usando Signals de Angular.
* **Filtros Avanzados:** Combinación de filtros por categoría, rango de precio y material.
* **CRUD Completo:** API RESTful preparada para Crear, Leer, Actualizar y Eliminar productos.
* **Diseño Premium:** Interfaz oscura, elegante y 100% responsiva (Mobile First).
